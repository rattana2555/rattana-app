    ⚙️ เชื่อมต่อ Google Drive

    วิธีติดตั้ง Apps Script (ทำครั้งเดียว)
    1. เปิด script.google.com → สร้างโปรเจกต์ใหม่
    2. ลบโค้ดเดิม วางโค้ดจากไฟล์ rattana-update-photo-shop-apps-script-v1.2.gs → กด Save
    3. เลือกฟังก์ชัน setup → กด Run → อนุญาตสิทธิ์
    4. Deploy → New deployment → Web app
      Execute as: Me · Who has access: Anyone
    5. คัดลอก Web app URL (ลงท้าย /exec) มาวางในช่องด้านบน → กดบันทึก
