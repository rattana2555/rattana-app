จอโฆษณาแคชเชียร์ v1.2

📖 วิธีตั้งค่าครั้งแรก (API Key + แชร์โฟลเดอร์)
1) แชร์โฟลเดอร์โฆษณา
  1. สร้างโฟลเดอร์ใน Google Drive → ใส่รูป (JPG/PNG) และวีดีโอ (MP4)
  2. คลิกขวาโฟลเดอร์ → แชร์ → เปลี่ยนเป็น "ทุกคนที่มีลิงก์" (ผู้มีสิทธิ์อ่าน)
  3. คัดลอกลิงก์โฟลเดอร์มาวางในช่องด้านบน
2) สร้าง API Key (ทำครั้งเดียว)
  1. เปิด console.cloud.google.com (ล็อกอินบัญชีบริษัท)
  2. เลือกโปรเจกต์เดิมของ Rattana (หรือสร้างใหม่)
  3. เมนู APIs & Services → Library → ค้นหา Google Drive API → กด Enable
  4. เมนู APIs & Services → Credentials → + Create Credentials → API key
  5. คัดลอก key มาวางในช่อง API Key (แนะนำ: กด Edit key → API restrictions → เลือกเฉพาะ Google Drive API)
3) เคล็ดลับ
  1. ไฟล์เรียงตามชื่อ — ตั้งชื่อ 01-โปรเบียร์.jpg, 02-นมผง.mp4 เพื่อกำหนดลำดับ
  2. ตั้งเวลารูปเฉพาะไฟล์ได้ โดยใส่ _15s ท้ายชื่อ เช่น โปรใหญ่_15s.jpg = แสดง 15 วินาที
  3. วีดีโอเล่นจนจบเสมอ แนะนำ MP4 (H.264) ขนาดไม่เกิน ~90MB ต่อไฟล์
  4. เพิ่ม/ลบไฟล์ใน Drive ได้เลย จอจะอัพเดทเองภายในไม่กี่นาที
4) ตั้งจอแคชเชียร์ให้เปิดเองตอนบูทเครื่อง
  1. คลิกขวาที่ Desktop → New → Shortcut แล้ววาง:
    "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --autoplay-policy=no-user-gesture-required "https://rattana2555.github.io/rattana-app/rattana-cashier-ads.html"
  2. ลาก shortcut ไปไว้ในโฟลเดอร์ Startup (กด Win+R พิมพ์ shell:startup)
  3. ปิด Sleep ของจอ: Settings → System → Power → Screen timeout = Never
