สูตรราคาขายต่อช่องทาง
ราคาขาย = (ราคาสุทธิที่ต้องการ + ค่าธรรมเนียมคงที่) ÷ (1 − ค่าธรรมเนียมรวม%) → ปัดตามกฎ
ค่าธรรมเนียมรวม% = คอมมิชชั่น + ค่าธุรกรรม/ชำระเงิน + อื่น ๆ (เช่น โปรแกรมส่งฟรี/โฆษณา) · สต็อกช่องทาง = สต็อกกลาง − จำนวนกันไว้ · ค่าเริ่มต้นเป็นแค่ตัวอย่าง ต้องปรับให้ตรงกับร้านของเรา

📄 ส่งออกไฟล์ราคา + สต็อก แยกตามช่องทาง

ไฟล์แต่ละช่องทางมีคอลัมน์ SKU · บาร์โค้ด · ชื่อสินค้า · หน่วย · ราคา · สต็อก · (ราคาสุทธิ/กำไร) — เอาไปวางลงเทมเพลตของ Seller Center หรือใช้หัวข้อถัดไปให้ระบบเติมให้เลย

แนวคิด

แก้ที่นี่ที่เดียว → ระบบคำนวณ ราคาขาย และ สต็อก ของทุกช่องทาง (Shopee / Lazada / Amaze / Thaimart / เพิ่มเองได้) จากกฎค่าธรรมเนียมของแต่ละช่อง → ส่งออกเป็นไฟล์ไปอัปโหลดใน Seller Center ของแต่ละแอพ

ขั้นตอน

  • ตั้งค่าช่องทาง — ใส่คอมมิชชั่น % / ค่าธุรกรรม % / กฎปัดราคา / จำนวนสต็อกกันไว้ ของแต่ละแอพ (แท็บ 🏪)
  • เพิ่มสินค้า — ดึงจากชีท PDDT (ค้นชื่อ/บาร์โค้ด แล้วเลือกหน่วย ชิ้น/แพ็ค/ลัง) หรือพิมพ์เอง หรือนำเข้า Excel
  • ใส่ต้นทุน + ราคาสุทธิที่ต้องการ + สต็อกกลาง — ราคาสุทธิ = เงินที่อยากได้เข้ากระเป๋าหลังหักค่าธรรมเนียม (เลือกหลายแถวแล้วกด "ตั้งราคาสุทธิ = ต้นทุน + %" ได้)
  • ระบบคำนวณราคาขายแต่ละช่องให้ — ต้องการราคาพิเศษบางช่อง ก็พิมพ์ทับได้ (สีทอง)
  • ส่งออก — ไฟล์ต่อช่องทาง หรือให้ระบบเติมลงเทมเพลตที่โหลดมาจาก Seller Center

สูตร

ราคาขาย = (สุทธิ + ค่าธรรมเนียมคงที่) ÷ (1 − %รวม) เช่น สุทธิ 120, %รวม 11.21 → 120 ÷ 0.8879 = 135.15 → ปัดลงท้าย 9 = 139
รับจริง = ราคาขาย × (1 − %รวม) − ค่าธรรมเนียมคงที่ · กำไร = รับจริง − ต้นทุน

ข้อควรรู้

  • ข้อมูลเก็บในเบราว์เซอร์เครื่องนี้ (localStorage) — กด 💾 เพื่อสำรองเป็นไฟล์ / กู้คืนในเครื่องอื่น
  • บาร์โค้ดที่ขึ้นต้นด้วย 0 จะถูกเก็บเป็นข้อความเสมอ ไม่ต้องกลัวเลข 0 หาย
  • สต็อกช่องทาง = สต็อกกลาง − กันไว้ (ไม่ต่ำกว่า 0) — ป้องกันขายเกินเมื่อหลายแอพขายพร้อมกัน
  • แอพนี้ยัง ไม่ได้ยิงเข้าแพลตฟอร์มอัตโนมัติ — เป็นเฟส 1: คิดราคาให้ + ทำไฟล์ให้ (Shopee/Lazada ต่อ API ได้ในเฟสถัดไป, Amaze/Thaimart ไม่มี API สาธารณะ)
