RATTANA ภาพหน้าร้าน v1.0
⚙️ ตั้งค่า Apps Script (ทำครั้งเดียว) ▼
⚠️ การอัพโหลดรูปไปยัง Google Drive จำเป็นต้องใช้ Apps Script เป็น backend ทำตามขั้นตอนด้านล่างเพียงครั้งเดียวครับ
1
เปิด Google Drive → สร้างโฟลเดอร์ใหม่ ตั้งชื่อ "ภาพหน้าร้าน" แล้วคัดลอก Folder ID จาก URL
เช่น: drive.google.com/drive/folders/1AbC2DeF3...
2
เปิด Google Sheet ของคุณ → Extensions → Apps Script
วางโค้ดนี้ลงไป แทนที่ทุกอย่างที่มีอยู่เดิม:
// ===== Rattana Store Photo Upload — Apps Script ===== // วาง code นี้ใน Google Apps Script แล้ว Deploy > New Deployment > Web App // Execute as: Me | Who has access: Anyone const SHEET_ID = '1dAxF4Mz-zhJIVbuJ_Ql126gt08qvVS1wndJD50pqCZI'; const LOG_SHEET = 'Photo Log'; const FOLDER_ID = '1GAaBfHDiV-RkKR0vHwmhofc-AufinaNo'; function doPost(e) { try { const data = JSON.parse(e.postData.contents); const ss = SpreadsheetApp.openById(SHEET_ID); let sheet = ss.getSheetByName(LOG_SHEET); // สร้าง Sheet ถ้ายังไม่มี if (!sheet) { sheet = ss.insertSheet(LOG_SHEET); sheet.appendRow(['วันที่/เวลา','ชื่อร้านค้า','ผู้บันทึก','หมายเหตุ','จำนวนรูป','URL รูปภาพ']); sheet.setFrozenRows(1); } const folder = DriveApp.getFolderById(FOLDER_ID); const urls = []; for (const img of (data.images || [])) { const bytes = Utilities.base64Decode(img.base64); const blob = Utilities.newBlob(bytes, img.mimeType, img.name); const file = folder.createFile(blob); file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW); urls.push('https://drive.google.com/uc?id=' + file.getId()); } sheet.appendRow([ data.datetime, data.storeName, data.recorder, data.notes || '', urls.length, urls.join('\n') ]); return ContentService .createTextOutput(JSON.stringify({ success: true, count: urls.length })) .setMimeType(ContentService.MimeType.JSON); } catch (err) { return ContentService .createTextOutput(JSON.stringify({ success: false, error: err.toString() })) .setMimeType(ContentService.MimeType.JSON); } } function doGet() { return ContentService .createTextOutput(JSON.stringify({ status: 'OK — Rattana Store Photo API ready' })) .setMimeType(ContentService.MimeType.JSON); }
3
ใส่ Folder ID ของคุณลงในบรรทัด FOLDER_ID แล้ว Save → Deploy → New Deployment
เลือก: Web App | Execute as: Me | Who has access: Anyone
→ Copy Web App URL ที่ได้
