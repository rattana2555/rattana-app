# Rattana Price Tag

ระบบสร้างป้ายราคาสินค้าสำหรับร้านค้ารัตน — ดึงข้อมูลจาก Google Sheet, พิมพ์ PDF A4 4 ป้าย/หน้า

## 🚀 เปิดใช้งาน
👉 **[https://rattana2555.github.io/rattana-app/rattana-price-tag.html](https://rattana2555.github.io/rattana-app/rattana-price-tag.html)**

## ✨ ฟีเจอร์
- 🎨 4 Template ป้ายราคา (ปกติ / ลดราคา / ใหม่ / ซื้อ 1 แถม 1)
- 📥 ดึงข้อมูลสินค้าจาก Google Sheet (PDDT) อัตโนมัติ
- 🔍 ค้นหา / กรองตามหมวดหมู่ / ประเภทป้าย
- 🖼️ แสดงรูปสินค้าจาก Google Drive
- 📊 QR Code + Barcode บนป้าย
- 📄 Export PDF ขนาด A4 (4 ป้าย/หน้า)
- 📱 ใช้งานได้ทั้งมือถือและคอมพิวเตอร์

## 📋 รูปแบบ Google Sheet
รองรับ 2 รูปแบบ:
1. **PDDT (Rattana Master)** — auto-detect คอลัมน์ CODE EA/CS, PRICE CC00-S03, SKU_USAGE
2. **Sheet เปล่า** — คอลัมน์: รหัสสินค้า, ชื่อสินค้า, ราคา, รูปภาพ, บาร์โค้ด, ฯลฯ
