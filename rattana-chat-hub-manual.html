1 เข้าใช้งานครั้งแรก

  1. เปิดลิงก์ Chat Hub (บันทึกไว้ในหน้าจอโฮมได้)
  2. กด เข้าสู่ระบบด้วย Google
  3. เลือกอีเมลบริษัท (@rattanaphaiboon.com หรืออีเมลที่ HR ลงทะเบียนไว้)
  4. เข้าได้เลย — ระบบจำไว้ ครั้งต่อไปไม่ต้องล็อกอินใหม่
⚠️ เข้าไม่ได้? ระบบให้เฉพาะพนักงานที่อยู่ในรายชื่อ HR เท่านั้น ถ้าใช้อีเมลส่วนตัวจะโดนเด้งออก — แจ้ง HR ให้เพิ่มอีเมลของคุณในชีทพนักงาน

📱 ติดตั้งบนมือถือ (ใช้เหมือนแอป)

  • iPhone: เปิดใน Safari → กดปุ่มแชร์ ⬆️ → เพิ่มลงหน้าจอโฮม
  • Android: เปิดใน Chrome → เมนู ⋮ → ติดตั้งแอป / เพิ่มลงหน้าจอหลัก

2 อ่าน & ตอบแชท

  1. แถบซ้ายคือ รายชื่อลูกค้า ที่ทักมา — จุดสี/ตัวเลขแดง = ยังไม่ได้อ่าน
  2. แถวบนมีปุ่มกรองช่องทาง: ทั้งหมดLINEFacebookShopeeTikTok กดเพื่อดูเฉพาะช่องนั้น
  3. แตะที่ชื่อลูกค้า → เห็นข้อความทั้งหมด รวมทั้ง รูป สติกเกอร์ ไฟล์
  4. พิมพ์ตอบในช่องล่าง กด ส่ง (หรือปุ่ม Enter)
💬 คำตอบด่วน: เหนือช่องพิมพ์มีปุ่มคำตอบสำเร็จรูป กดแล้วส่งได้เลย ไม่ต้องพิมพ์
สวัสดีครับ 🙏รับทราบครับ ✓รอสักครู่นะครับ จัดส่งภายใน 2-3 วันครับ 📦กรุณาส่ง slip ด้วยครับขอบคุณที่ใช้บริการครับ 🙏
✅ ตอบจากที่ไหนก็เห็นตรงกัน: ถ้าเพื่อนตอบลูกค้าในแอป LINE OA หรือใน Shopee โดยตรง ข้อความนั้นจะเด้งกลับมาแสดงใน Chat Hub ให้เองด้วย — ทีมเห็นตรงกันเสมอ ไม่ตอบซ้ำ

3 ช่องไหนตอบได้ / ตอบไม่ได้

แต่ละแพลตฟอร์มมีกฎต่างกัน (เป็นกฎของเจ้าของแพลตฟอร์มเอง ไม่ใช่ระบบเรามีปัญหา) — เปิดแชทแล้วระบบจะบอกให้เองว่าตอบได้ไหม

ช่องทางอ่านแชทตอบจาก Hub
LINEได้ได้ *
Facebookได้ได้ ใน 24 ชม.
Shopeeได้ตอบใน Shopee
TikTokได้ตอบในแอป TikTok

ถ้าเปิดแชทแล้วขึ้นแถบเหลือง ⚠️

  • "เกินกำหนด 24 ชม." (Facebook) → ลูกค้าทักนานเกินไป ตอบไม่ได้จนกว่าเขาทักมาใหม่ — เป็นกฎของ Facebook กันสแปม
  • "ตอบใน LINE OA Manager แทน" → แชท LINE เก่าที่ระบบดึงมาก่อนติดตั้ง ตอบใน Hub ไม่ได้ แต่ ตอบใน LINE OA ได้ตามปกติ แล้วเด้งกลับมาโชว์ที่นี่ · แชทนี้จะตอบจาก Hub ได้เองเมื่อลูกค้าทักมาใหม่
  • "ตอบใน Shopee / แอป TikTok" → สองช่องนี้ไม่เปิดให้ระบบข้างนอกตอบแทน ให้ตอบในแอปของมันเอง
* LINE: ตอบจาก Hub ได้เฉพาะแชทที่ลูกค้าทักมาหลังติดตั้งระบบ ส่วนแชทเก่าให้ตอบใน LINE OA (ระบบบอกให้เองตอนเปิดแชท)

4 แจ้งเตือนเมื่อมีคนทัก

  1. กดรูป กระดิ่ง 🔔 มุมขวาบน เพื่อเปิดเสียงแจ้งเตือน
  2. ครั้งแรกเบราว์เซอร์จะถามขออนุญาต → กด อนุญาต / Allow
  3. พอมีลูกค้าทักใหม่ จะมี เสียงเตือน + เด้งข้อความ แม้เปิดแท็บอื่นอยู่
ไม่ต้องคอยกดรีเฟรช — ระบบดึงข้อความใหม่ให้เองอัตโนมัติ แชทที่มีการเคลื่อนไหวจะเด้งขึ้นบนสุดเอง
💡 เคล็ดลับ: เปิด Chat Hub ค้างไว้ในแท็บนึงของคอมตลอดวัน จะได้ยินเสียงเตือนทันทีที่ลูกค้าทัก

5 ส่วนขยาย — เครื่องที่ดูแล Shopee/LINE/TikTok

Shopee กับ TikTok ไม่เปิดให้ดึงแชทตรงๆ เราจึงใช้ ส่วนขยาย Chrome อ่านจากหน้าที่พนักงานเปิดอยู่แล้วส่งเข้า Hub — ติดตั้งแค่เครื่องที่เปิดหน้าพวกนี้ประจำ 1 เครื่องพอ (ไม่ต้องทุกคน)

วิธีให้ส่วนขยายทำงาน

  1. เปิด Chrome บนเครื่องที่ติดตั้งส่วนขยายไว้
  2. เปิดหน้าแชทของแพลตฟอร์มค้างไว้:
    • Shopee → Seller Center หน้าแชท
    • LINE → LINE OA Manager
    • TikTok → หน้า Messages (tiktok.com/messages)
  3. แค่นั้น — ส่วนขยายจะอ่านแล้วส่งเข้า Hub เองอัตโนมัติ
⚠️ TikTok: เปิดหน้า Messages ค้างไว้ ระบบจะไล่ดึงแชทเองทุก 10 นาที (เฉพาะตอนไม่มีคนใช้เครื่อง) · ถ้าอยากดึงเดี๋ยวนี้ กดไอคอนส่วนขยาย → ดึงแชท TikTok ทั้งหมดเดี๋ยวนี้
ปลอดภัย: ส่วนขยาย อ่านอย่างเดียว ไม่ล็อกอินแทน ไม่ตอบแทน ไม่เก็บรหัสผ่าน — แค่อ่านข้อมูลชุดเดียวกับที่พนักงานเห็นบนจอ แล้วส่งต่อมาให้ Hub

6 ปัญหาที่พบบ่อย

❓ เข้าแอปแล้วเด้งออกทันที

อีเมลที่ใช้ยังไม่อยู่ในรายชื่อพนักงาน — แจ้ง HR เพิ่มอีเมลในชีท แล้วลองใหม่

❓ แชทเก่าไม่ขึ้น / ข้อมูลไม่อัปเดต

ดึงหน้าลงเพื่อรีเฟรช หรือปิด-เปิดแอปใหม่ · ถ้าเปิดบนคอม กด Ctrl+Shift+R

❓ ตอบแล้วขึ้น ⚠️ สีเหลือง

อ่านข้อความในแถบเหลือง มันบอกสาเหตุจริงให้เลย (ดูหัวข้อ 3) — ส่วนใหญ่คือให้ไปตอบในแอปของช่องทางนั้นแทน

❓ Shopee/TikTok ไม่มีแชทใหม่เข้ามา

เช็คว่าเครื่องที่ติดตั้งส่วนขยาย เปิดหน้าแชทของแพลตฟอร์มนั้นค้างไว้ อยู่หรือเปล่า — ถ้าปิดหน้าไป ระบบจะอ่านไม่ได้

❓ ไม่ได้ยินเสียงเตือน

กดกระดิ่ง 🔔 ให้เป็นสีเปิด และตอนเบราว์เซอร์ถามให้กดอนุญาต · บางเครื่องต้องคลิกบนหน้าเว็บ 1 ครั้งก่อนเสียงถึงจะทำงาน
