# Rattana Stock — สรุปงาน (แนว B)

> ปรับแอปนับสต็อก **Rattana Stock** ให้ใช้ง่ายขึ้น — เลือกใช้ **แนว B (Live list)** เป็นฉบับหลัก · ใช้ได้ทั้งมือถือ + คอม · ธีมน้ำเงินเข้ม · ต้นแบบกดเล่นได้ (ยังไม่ต่อระบบจริง)

---

## 1. โจทย์
แอปเดิม (`uploads/rattana-stock-checker.html`) ผู้ใช้แจ้งว่าใช้ยาก: ปุ่ม/ตัวอักษรเล็ก · ไอคอน/อีโมจิรก · ไม่รู้ว่าอยู่ขั้นไหน · นับ+แก้จำนวนยุ่งยาก · สแกนวุ่นวาย · หน้าสรุปอ่านยาก

**ทิศทาง:** มือถือ (และต่อมาเพิ่มคอม) · ธีมน้ำเงินเข้ม · ใช้มือเดียวได้ · คงรูปแบบ **CS.EA**

> เคยทำ 3 แนวเทียบกัน (A Guided / B Live list / C Keypad) → **เลือกแนว B** มาพัฒนาต่อเป็นฉบับใช้งานจริง

---

## 2. ระบบดีไซน์
- **ธีมน้ำเงินเข้ม** — พื้นหลังสว่างอ่านง่าย, navy เป็นสีหลัก (header/ปุ่ม/ตัวเลข), accent ฟ้า
- **ไอคอนเส้น** แทนอีโมจิทั้งหมด → สะอาดขึ้น
- **ปุ่มหลัก 56–64px, ตัวเลข 30–42px** — กดมือเดียวได้
- สถานะสี: **ตรง = เขียว · ขาด = แดง · เกิน = เหลือง**
- คงรูปแบบ **CS.EA** (เลขหลังจุด = จำนวน EA ตรงตัว เช่น `3.05` = 3 ลัง 5 ชิ้น)

## 4. ฟีเจอร์แนว B (ฉบับใช้งาน)

**หน้านับ**
- แถวในหน้าหลัก **โชว์สะอาด** (ชื่อ · นับ/ระบบ · สถานะ · ลูกศร)
- **แตะแถวเพื่อกาง** → ขึ้นปุ่ม +/−, ช่องพิมพ์จำนวนแต่ละหน่วย (CS/PA/EA) และปุ่มลบ
- ปรับจำนวนได้ทั้ง **ปุ่ม +/− และพิมพ์ตัวเลขในช่อง**

**ช่องสแกน / บาร์โค้ด**
- รองรับ **เครื่องยิงบาร์โค้ด USB** (ยิงแล้วกรอกอัตโนมัติ) และ **พิมพ์เลข + Enter**
- มีปุ่มกล้องสำหรับมือถือ + ชิปตัวอย่างโค้ดให้ทดสอบ

**สแกนแล้วใส่จำนวนก่อน** (ไม่ +1 อัตโนมัติ)
- ยิง → การ์ด "ใส่จำนวนที่นับได้" เด้งบนสุด (ช่องจำนวนโฟกัสเอง) → พิมพ์/กดจำนวน เลือกหน่วยได้ → **Enter / เพิ่มเข้ารายการ** → โฟกัสกลับช่องสแกน
- USB workflow: **ยิง → พิมพ์เลข → Enter → ยิงต่อ** (ค่าเริ่มต้น 1 กด Enter ผ่านได้)
- ช่วยให้ไม่ต้องเลื่อนหาเพื่อแก้จำนวนทีหลัง

**หน้าสรุปผล**
- **แถวสั้นกระชับ** เห็นหลายรายการ (แถบสีซ้าย + ป้ายตัวเลขขวา)
- ใช้คำ **ขาด/เกิน** · ชิปสถานะเป็น **CS.EA** (เช่น `ขาด 4 CS 17 EA`)
- การ์ดสรุป ตรง/ขาด/เกิน ด้านบน

---

## 5. ใช้บนคอมพิวเตอร์
จอกว้าง ≥ 980px → **layout เต็มจอ 2 ฝั่งอัตโนมัติ** (ไฟล์เดียวกัน):
- **ซ้าย** — ช่องสแกน (โฟกัสอัตโนมัติ รองรับ USB scanner) + รายการที่นับ + ล้างทั้งหมด
- **ขวา** — **สรุปผลสด** อัปเดตทันทีทุกครั้งที่ยิง/แก้ + ปุ่ม Excel / บันทึกผล
- หน้า Login / เลือกคลัง จัดกึ่งกลางสวยงาม

---

## 6. หมายเหตุ (ต้นแบบ)
- ข้อมูลตัวอย่าง 8 สินค้า · มี seed รายการนับให้หน้าสรุปดูมีของ
- **ยังไม่ต่อระบบจริง** (Google Login / กล้องสแกน / Google Sheet เป็นการจำลอง)
- โค้ด USB scanner ทำงานเหมือนคีย์บอร์ดพิมพ์เลข+Enter — ตรงกับช่องที่ออกแบบไว้ พร้อมต่อระบบจริง

- ต่อระบบจริง (Sheet / Login / กล้อง)
